# Legislative Quality and Large Language Models

This repository contains the data processing and analysis code used in the study:

"Identifying quantitative factors for evaluating legislative quality using large language models"

submitted to *Humanities and Social Sciences Communications*.

The repository includes scripts for extracting quantitative features from legislative texts,
constructing a silver-standard label using large language models,
and conducting hypothesis testing.

---

## Repository Structure

### Data Processing/

This folder contains all scripts and resources used to extract quantitative indicators
from legislative bills.

#### Raw Data
- `bill_pdfs/`  
  Contains 2,785 legislative bill documents collected from the official website.

#### Feature Extraction Scripts
Each script extracts one quantitative feature from the legislative texts:

- `fetch_bill_avg_sentence_length.py`  
  Computes average sentence length.

- `fetch_bill_dates.py`  
  Calculates time between bill proposal and passage.

- `fetch_bill_exceptions.py`  
  Measures frequency of adversative and exception expressions.

- `fetch_bill_foreign_words_count.py`  
  Counts foreign word usage.

- `fetch_bill_meeting_counts.py`  
  Extracts the number of committee meetings.

- `fetch_bill_members.py`  
  Calculates the number of co-sponsors.

- `fetch_bill_parties.py`  
  Measures party diversity among sponsors.

- `fetch_bill_seniority.py`  
  Computes sponsoring legislator seniority.

- `fetch_bill_vague_terms.py`  
  Detects vague or ambiguous expressions.

- `fetch_bill_vocab_level.py`  
  Calculates vocabulary level using a predefined lexical standard.

#### Silver Standard Construction
- `fetch_silver_standard.py`  
  Generates the silver-standard legislative quality label using LLM-based evaluation.

- `silver_standard_results.csv`  
  Output file containing generated silver-standard labels.

#### Dictionaries / External Resources
- `foreign_examples.csv`  
  Dictionary used to detect foreign terms.

- `국어 기초 어휘 선정 및 어휘 등급화 목록 전체.csv`  
  Official lexical standard used for vocabulary level analysis.

---

### Analysis

- `Experiment.ipynb`  
  This notebook performs the statistical analyses and hypothesis testing
  using the features generated by the scripts above.

  It includes:
  - Data integration
  - Model estimation
  - Robustness checks
  - Visualization of results

---

## Reproducibility

To reproduce the analysis:

1. Run feature extraction scripts in the `Data Processing/` folder.
2. Generate the silver-standard label using `fetch_silver_standard.py`.
3. Execute `Experiment.ipynb` to reproduce hypothesis testing and figures.

All analyses were conducted in Python.
